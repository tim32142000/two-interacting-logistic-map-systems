# State-continuation bifurcation experiment

2026-10-25 · Two output-coupled logistic maps

## Question

Does the visible period-2 region continue to the right, perhaps coalescing into period-1, if a parameter sweep uses the final state at the previous k instead of restarting from a fixed initial condition?

## Method

We re-used the 2026-10-18 model and numerical conventions. The full scan covers 551 k values spanning 0 to 0.5; a targeted scan uses 501 points between k=0.135 and 0.16 (step 0.00005). Each direction is run independently. At the first k, the state is generated by 249 uncoupled iterations from (0.12924,0.2304); at subsequent k values, **the final state at the preceding k** is the starting state. Each k discards 12,000 iterates, measures 8,192 and plots the last 64. A period is detected only if the entire 1,024-point tail repeats within absolute tolerance 1e-8 for one p in 1..64. Largest Lyapunov exponent uses the analytic 2x2 Jacobian and tangent normalization.

Both local directional sweeps classify the 207 sampled k values in [0.135,0.14530] as common period-2. The next k sample, 0.14535, shows no detected period <=64 and a positive largest Lyapunov exponent. The sampled attractor transition thus lies inside **(0.14530,0.14535]** at the chosen resolution, tolerance and finite measurement time. The broad scans reproduce 0.1025..0.145 as the common period-2 window; both directions show the same sampled period labels in the local window.

The code validates numerically that start_x(k_i)=end_x(k_{i-1}) and start_y(k_i)=end_y(k_{i-1}) to exact floating-point equality for all adjacent k values in every scan.

## Interpretation

The state-continuation sweep does **not** make the observed period-2 attractor smoothly merge into a period-1 attractor on the right. The two scalar state branches remain separated at k=0.14530; by k=0.14535 the sampled motion appears irregular, with positive finite-time Lyapunov exponent. Changing the way initial conditions are carried across k did not eliminate the abrupt boundary in these scans. Across the two sweep directions there is no evident period-2 hysteresis at this resolution, though isolated attractors and narrow windows cannot be excluded.

**Critical limitation:** Iterating the map follows *attractors*, not generally an unstable solution branch. Even if an unstable period-2 solution extends beyond this window, forward iteration will not track it. To answer whether period-2 mathematically disappears or merely loses stability, solve F_k²(z)=z using numerical continuation **to the right**, evaluate both Floquet multipliers, check F_k(z)-z to detect convergence into a fixed point, and use pseudo-arclength continuation around a fold if necessary. The prior experiment's refine.py only continued period-2 to the left from k=0.12.

This is a finite-length double-precision computational observation, not a rigorous proof of bifurcation type, chaos or global attractor uniqueness.
